# Data Dictionary

| Column Name | Description | Business Meaning |
|---|---|---|
| LoanID | Unique loan identifier | Identifies each loan |
| Age | Customer age | Used for customer segmentation |
| Income | Customer income | Used for affordability and risk analysis |
| LoanAmount | Requested loan amount | Used for loan portfolio analysis |
| CreditScore | Customer credit score | Used for risk classification |
| MonthsEmployed | Employment duration | Indicates customer stability |
| NumCreditLines | Number of credit lines | Indicates financial exposure |
| InterestRate | Loan interest rate | Used for profitability analysis |
| LoanTerm | Loan duration | Used for repayment analysis |
| DTIRatio | Debt-to-income ratio | Key risk indicator |
| Education | Customer education level | Used for segmentation |
| EmploymentType | Employment status | Used for risk analysis |
| MaritalStatus | Customer marital status | Used for demographic analysis |
| HasMortgage | Mortgage ownership | Financial liability indicator |
| HasDependents | Dependents indicator | Financial burden indicator |
| LoanPurpose | Purpose of the loan | Business segmentation |
| HasCoSigner | Co-signer availability | Risk mitigation indicator |
| Default | Loan default flag | Main risk outcome variable |
