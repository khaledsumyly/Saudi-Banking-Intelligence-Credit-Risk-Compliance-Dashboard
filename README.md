Saudi Banking Intelligence & Credit Risk Dashboard

An end-to-end banking analytics and decision-support system built using SQL, Python, and Power BI to analyze credit risk, customer behavior, operational performance, and compliance monitoring.

⸻

🚀 Overview

This project simulates a real banking environment, transforming raw data into actionable insights to support:

* Credit risk analysis
* Customer segmentation
* KPI monitoring
* Compliance and governance tracking
* Executive-level decision-making

⸻

🎯 Business Objectives

* Monitor key banking KPIs and performance indicators
* Identify high-risk customers and loan segments
* Analyze customer behavior and segmentation patterns
* Detect compliance exceptions and risk signals
* Support data-driven decision-making

⸻

🛠️ Tech Stack

* SQL — Data cleaning, transformation, and feature engineering
* Python (Pandas) — Data validation and preprocessing
* Power BI — Dashboard development and data visualization
* DAX — KPI calculations and analytical measures
* Power Query — Data shaping and transformation
* Excel — Supporting analysis

⸻

📊 Key KPIs

* Default Rate %
* Average Loan Amount
* Credit Score Distribution
* High-Risk Customer Count
* Loan Distribution by Category

⸻

🧠 Key Features

* Customer segmentation (income, loan size, age group)
* Risk categorization model
* KPI-based performance tracking
* Compliance and exception monitoring
* Executive dashboard for decision support

⸻
