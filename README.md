# Saudi Banking Intelligence, Credit Risk & Compliance Dashboard

## Overview
An executive-level banking intelligence and decision-support dashboard focused on credit risk analysis, customer intelligence, digital transformation metrics, and compliance monitoring.

## Objectives
- Monitor banking KPIs
- Analyze customer and loan risk
- Track digital adoption
- Detect compliance exceptions
- Support executive decision-making

## Core Tools
- Power BI
- SQL
- Power Query
- DAX
- Excel
- Python (Optional)

## Project Structure

/data → Raw and cleaned datasets

/sql → SQL queries and transformations

/powerbi → Power BI files (.pbix)

/docs → Documentation and KPI definitions

/screenshots → Dashboard screenshots
